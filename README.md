# Emerging Technologies Centre (ETC)

The Emerging Technologies Centre (ETC) at Lancaster University Ghana (LUG) is an innovation hub for research and practical learning. Opened in 2025, it provides a platform for students and researchers to work with Artificial Intelligence (AI), Robotics, and Blockchain.

## Technologies & Facilities

The centre provides hardware and software to connect academic theory with practical application:

* **Robotics:** Unitree Go2 EDU and Mercury X1 humanoid robots for autonomous navigation and machine learning research, plus MyCobot robotic arms for automation training.
* **Mixed Reality:** Meta Quest 3 headsets for educational simulations.
* **Hardware Development:** Volterra V One PCB Printer for rapid prototyping of IoT and embedded systems.
* **Lab Spaces:** An AI Maker Space, IoT learning kits, and blockchain simulation tools.

## Educational Initiatives

The ETC runs several outreach and training programs:

* **Emerging Technologies Bootcamp:** An 8-week program (supported by the KGL Foundation) introducing Senior High School students from underserved communities to coding, robotics, and 3D printing.
* **Weekend Immersive Training:** Practical ICT workshops for teachers and students, focusing on computational thinking and Python programming.
* **Professional Development:** AI and Machine Learning training for corporate professionals to build data analytics and predictive modeling skills.
